# 汽车车门转运车架（CATIA V5 课程项目）

本项目为 CATIA V5 产品设计课程作业：**汽车车门转运车架**（焊接方管框架），用于汽车门板的立式存放与转运。

## 目录说明

| 目录 | 内容 |
|---|---|
| `CAD/` | CATIA 装配 `DoorRack3.CATProduct` 及所用 11 种零件的 `.CATPart` |
| `report/` | CATIA 产品设计报告（Word） |
| `images/` | 总装配等轴测截图、A3 工程图图样 |
| `step/` | 总装配 STEP 汇总文件 |

## 主要参数

- 总体：长 2400 × 宽 1000 × 高 800 mm（含门架总高 1113）
- 空心方管：40×40×2.5
- 顶部纵向梁：11 根，宽向间距 20cm
- 立柱：13 根（4 根角柱带把手）
- V 型定位小梁：10 根
- 门架支撑单元：8 个（U 型梁 580 + 双立柱，高 153）
- 端部水平方管：2 根，40×153×250

## 软件

- CATIA V5 （R20+）

## 项目技能（Codex Skill）

仓库内置一个 Codex 技能：**`catia-door-rack`**。它是一个"说明书"，让 AI 助手（Codex/Claude）能在这个项目上自动完成建模、修改和出图，而不用每次都从零摸索。

### 它能做什么

- **重建模型**：按项目参数一键重建整套车架（11 根顶梁、13 立柱、10 根 V 型定位梁、8 个门架、端部方管）。
- **改尺寸/位置**：改某个梁/柱/门架的尺寸或坐标（改参数，不是手动重画）。
- **加构件**：新增立柱/横梁/支撑。
- **导出**：生成 STEP、Word 报告、A3 工程图（BOM + 三视图 + 等轴测 + 零件序号）。
- **出工程图教程**：说明了在 CATIA 里用 A3 图框 + 零件序号 + BOM 的标准操作。

### 目录结构

```
catia-door-rack/
├── SKILL.md                      # 技能说明与工作流
├── agents/openai.yaml            # 技能 UI 元数据
├── references/dimensions.md      # 全部尺寸与坐标（修改时的单一事实来源）
└── scripts/                      # 建管、装配、门架、端管、导出、报告等 11 个脚本
```

### 怎么用

- 打开本项目，直接对 Codex 说："用 catia-door-rack 技能重建/修改模型"或"导出报告"。
- 想改参数：看 `references/dimensions.md`，改对应脚本里的数值，再跑对应脚本。
- 想让 AI 全局可用：把 `catia-door-rack/` 复制到 `~/.codex/skills/`。
